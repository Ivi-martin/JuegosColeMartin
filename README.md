# JuegosColeMartin
Jueguecitos para la clase de Martín

## Cómo jugar
Enlace principal (GitHub Pages): `https://TU_USUARIO.github.io/JuegosColeMartin/LaRuleta/`

- **LaRuleta/** → juego principal. Al abrirlo se reproduce el vídeo de presentación (`portadaRuleta.mp4`) y después empieza el juego.
- **SuperReto/** → minijuego que se abre solo desde la ruleta cuando cae en la casilla *SUPER RETO*. Los puntos conseguidos se usan para elegir consonante (si saca 0, se pierde el turno).

> LaRuleta y SuperReto deben estar siempre en carpetas hermanas (la ruleta carga `../SuperReto/index.html`).
